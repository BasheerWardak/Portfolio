# Basheer Wardak — Portfolio Website

🚀 Personal portfolio website showcasing my projects, resume, and professional links.  
Built with **HTML, CSS, JavaScript**, and hosted with **GitHub Pages**.

🌐 Live Site: https://basheerwardak.github.io/Portfolio/

---

## ✨ Overview
This website is a lightweight, responsive portfolio designed to help recruiters and hiring teams quickly learn about my background, skills, and technical projects.

It includes:
- An **About** section
- A **Projects** section (with screenshots + GitHub links)
- A **Resume download** button
- GitHub + LinkedIn contact links
- Optional **Dark Mode** toggle

## ▶️ Run Locally
You can run this site locally by opening the HTML file directly:

1. Download or clone this repository
2. Open `index.html` in your browser

Recommended (VS Code):
- Install **Live Server**
- Right click `index.html` → **Open with Live Server**
